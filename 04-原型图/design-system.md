# 校园超市线上订货与自提系统 · 视觉规范

## 1. 设计方向
校园轻快风格：青绿主色传达「新鲜、可靠」，暖黄点缀强调待办与价格。门户以卡片 + 时段胶囊为主，
备货工作台按大按钮设计（适合手持操作），核销台以居中取货码输入框为视觉焦点。

## 2. 色彩
| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | `#16695C` | 顶部栏、主按钮、当前菜单、关键数字 |
| 辅助色 | `#3D9683` | 次级按钮、筛选选中态、图表系列 |
| 强调色 | `#E0A32E` | 待办数量、价格、对比系列 |
| 页面背景 | `#F5F6F7` | 内容区背景 |
| 正文 | `#1F2933` | 标题正文；次要信息 `#5B6770` |
| 成功 | `#2B7955` | 已完成、已核销、正常 |
| 危险 | `#B02A37` | 驳回、超时、删除，仅小面积 |

状态不只靠颜色表达，标签内始终有中文。

## 3. 字体阶梯
- 页面标题 20px / 700
- 区块标题 15px / 600
- 正文 14px / 400
- 次要信息 12.5px / 400
- 关键数字 21–30px / 700，`letter-spacing:-0.5px`

## 4. 间距与圆角
- 内容区外边距 24px，卡片内边距 16–18px，卡片间距 14px
- 圆角：卡片 10px、按钮 8px、胶囊 22px、头像 50%
- 阴影：`0 2px 10px rgba(31,41,51,.06)`

## 5. 栅格
- 桌面端 220px 侧栏 + 56px 顶栏 + 自适应内容区
- 看板 4 列 KPI，图表 2 列（1.55fr / 1fr）
- 1440×900 一屏不出现滚动条

## 6. 角色视觉区分
后台 6 类角色共用管理骨架，通过菜单权限与顶栏身份区分；学生门户独立骨架（顶部导航 + 卡片流 + 底部购物车悬浮条）。
